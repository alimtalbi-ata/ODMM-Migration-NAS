# ODMM V228.98 — Fencing de la chaîne des ancêtres (laboratoire POSIX)

**Auteur : Abdelhalim Talbi** — 23 octobre 2026

## Problème
Le contrôle V228.97 maintenait ouvert le répertoire parent immédiat, mais un répertoire plus haut dans le chemin pouvait être renommé et remplacé par un lien symbolique pendant le calcul SHA-256. Le contrôle du seul parent ne démontrait pas la stabilité de l'ensemble du chemin.

## Correction
Le module `odmm_linux_lab_path_fence.py` ouvre depuis la racine tous les ancêtres, composant par composant, avec `O_DIRECTORY | O_NOFOLLOW`. Les descripteurs restent ouverts pendant la lecture. Le moteur vérifie à l'entrée, avant la lecture et à la sortie que chaque nom pointe toujours vers le couple `(st_dev, st_ino)` conservé. Il refuse les composants symboliques et les segments lexicaux `..`.

Le vérificateur de copie indépendant et l'inspecteur des preuves SQLite utilisent désormais le même contrôle. Une substitution détectée entraîne un refus de validation ou une preuve d'identité non conforme. **Aucun nettoyage, replay, promotion de UNCERTAIN ni migration NAS n'est autorisé.**

## Qualification et preuves
Cinq nouveaux tests déterministes couvrent : lecture normale imbriquée, ancêtre symbolique initial, substitution par lien symbolique pendant le hachage, substitution par répertoire pendant le hachage et refus de `..`. Le workflow Linux Full/Compact les exécute, en plus des suites historiques. Les résultats GitHub Actions doivent être vérifiés séparément avant toute mention « CI verte ».

## Limites
C'est une détection POSIX locale, **pas** un snapshot atomique : un remplacement puis rétablissement entre deux vérifications peut échapper au contrôle (ABA). Les points de montage, les espaces de noms, les renumérotations d'inodes et les changements distants NFS/SMB ne sont pas qualifiés. Le SHA-256 du journal SQLite n'est pas une signature : un acteur capable de modifier simultanément le journal et son empreinte peut falsifier les preuves. Les ACL NFSv4/NTFS, SID, xattrs, multi-nœuds, crash électrique, Windows et NAS de production ne sont pas qualifiés.
